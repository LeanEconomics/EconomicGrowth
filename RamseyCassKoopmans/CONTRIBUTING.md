# Contributing

Contributions of original work are accepted under the Unlicense. Preserve
third-party notices and identify copied or adapted material and its license.

State the economic model, domain, regularity, welfare criterion and source
version explicitly. Distinguish candidate verification from path construction.
Do not use `sorry`, extra axioms, unchecked solver results, or assumptions which
silently restate the conclusion. Run `python scripts/verify.py` before proposing
changes. Keep the source map and proof-status document accurate.
